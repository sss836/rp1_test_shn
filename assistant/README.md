# RP1 Pi 助手（规划 v1，第2—4项）

当前桥接源码版本为 `0.4.0`，Pi 依赖继续固定为 `@earendil-works/pi-agent-core` / `pi-ai` 1.4.0，传递依赖及完整性见 `package-lock.json`；Node 22.22.0 镜像固定 digest。部署门禁、任务快照及恢复步骤见[运行说明](../docs/ASSISTANT-RUNTIME.md)。实际启用与验收状态以对应任务交付记录为准。

## 入口与查询

全局“助手”入口打开右侧面板。发送前显示当前页面、模块/整机、对象、归档、指标、测量对象、区间及阶段/循环；提交时冻结上下文。工作台聚焦面板用于确定指标，当前归档用于确定数据来源；比较视窗不与该归档重叠时明确提示，禁止改用全程统计。查询其他明确归档时不携带原归档的选区。

链路为浏览器同源 `/api/v1/assistant/jobs` → FastAPI 真实登录会话 → Pi 独立容器 → DeepSeek 官方 `https://api.deepseek.com` / `deepseek-flash` → 固定业务回调。浏览器 Cookie 留在 FastAPI；Pi 仅拿到不超过120秒的任务授权。每次工具调用重新核对原会话、当前角色、试点名单及任务状态，业务访问继续受数据库 RLS 和对象权限约束。授权不会增加测试数据审批权。

固定工具如下，不存在 SQL、shell、任意 URL、设备控制、归档提交或审批工具：

| 工具 | 实际行为 |
|---|---|
| `get_curve_statistics` | 复用 `CurveAnalysisService.select/statistics` 对归档原始范围作精确统计；附原始文件哈希、范围、各序列单位、来源与查询时间；不从绘图抽样或模型文字计算数字。 |
| `get_test_progress` | 当前权限下的计划配置项数、执行状态计数和更新时间，最多30个计划并标明截断；不将待审批结果转入正式统计。 |
| `list_hmi_stations` | 最新工位心跳快照及每项最后更新时间，最多50项并保留游标；不诊断运行曲线。 |
| `apply_setup_bundle` | 复用第3项真实用户权限下的整组事务、幂等回执、字段来源核对与建议采用；每个任务最多一次整组写入。 |

结果卡片由后端回执构造，模型不能指定外部跳转地址。链接仅允许已有对象页面，项目/计划/样品/用例/台架按实际保存类型导航。普通页面和助手写入共用第3项业务服务，管理员和执行员创建者可继续管理，关联已有计划仍需编辑权。用例默认草稿；发布完整度、文字判据不自动通过及追加版本规则继续有效。

## 会话、排队与时限

`integration.assistant_thread/message/job` 按账号隔离。聊天正文、卡片和页面上下文只保留30天：读取立即过滤到期正文，后台每60秒和进程启动执行删除/清空；原业务对象、整组回执、行审计及财务审计独立长期保留。财务审计仅记录任务标识、费率和用量，不保存聊天正文。不能以聊天到期删除业务证据。

一个 API 进程运行两个 FIFO 消费者，超出两个任务进入等待队列（最多100个等待项）。API 必须使用单 worker；QA Compose 固定 `--workers 1`，应用拒绝 `WEB_CONCURRENCY != 1`。不支持多副本调度。任务从开始执行起最多120秒（排队等待时间另计），最多6次实际模型请求；每次调用最长30秒、输出最多4096 Token，无隐式重试。等待模型期间不持有数据库事务。任务上下文不随页面切换改变，面板收起后仍可核对任务，切换账号清除前一个账号的界面与订阅。

`POST /jobs` 在提交短事务内冻结消息边界、输入快照及哈希，模型、字段授权与审计统一使用快照；后发消息不影响先发任务。请求键与消息、上下文绑定；丢失提交响应时复用原键查询原任务，不再次执行。`GET /jobs/{id}` 在断流、超时、取消后核对数据库中的实际整组回执，已保存对象不会自动撤销。用户可以停止排队或执行中的任务，停止后拒绝新增工具；已开始的短事务按真实提交结果处理。API 重启时旧等待/运行任务标记中断，内存 Cookie、授权及未采用提议失效，不自动用替代身份重放。已提交回执仍可查询。

## 站点预算与失败恢复

站点每日合计上限100元，以 `Asia/Shanghai` 的日期分桶，零点开始新桶；跨日请求仍在发起预留的日期结算。所有运行模式的新增模型请求必须先经私网回调预留；短事务串行更新全站余额，不能由两个并发请求共同透支。

截至2026-10-22核对的 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)：Flash 高峰输入/缓存命中/输出为每百万 Token 2/0.04/8元。当前实现全天按高峰价格记保守费用上界，不是供应商账单。调用前按锁定模型完整输入上限1,000,000 Token及4096输出 Token预留 **2.032768元**，调用后仅依据原始 SSE `usage` 中完整、相互一致的实际 Token 计数结算并释放余量。保守预留可能使实际费用较低但可用余额不足的任务提前停止，这是已实现策略。

`ASSISTANT_PRICE_VALID_UNTIL` 默认 `2026-10-29T00:00:00+08:00`；过期或格式不可靠时停止新增模型调用，须由获授权维护人员重新核对官方费率后调整。不能只延长日期而不核对价格和模型上限。

缺少/无效用量、供应商断流、超时未结算或重启时存在未结算调用，均保留完整预留并将全站财务状态置为待核对，跨午夜与重启继续阻止新增调用。已取得可靠结算的调用不重复扣费。没有自动解除冻结或猜测零费用的功能；需获授权维护人员结合供应商用量/账单逐条核对 `assistant_model_call` 和对应日桶后处理，留存操作证据，不能直接清空财务表或盲目释放预留。普通业务仍可使用，冻结模型调用不撤销真实业务回执。

迁移 `20261022_0049` 为追加表、RLS及有限用途函数，承接0048；0050增加不可变任务快照和30天清理。`assistant_finish` 只完成原账号任务元数据并核对真实业务回执，即使原账号在等待时被停用也能完成收尾，不能写业务对象。迁移禁止破坏性降级。恢复先关闭助手入口，保留任务、业务与财务证据，再按已核对版本恢复应用；不得删表回滚。

## 配置和隔离验证

入口默认关闭：`ASSISTANT_ENABLED=false`、`ASSISTANT_RUNTIME_ENABLED=false`。仍需 session认证及指定管理员/执行员名单。生产环境另外要求 `ASSISTANT_PRODUCTION_ENABLED=true`、Secure Cookie、任务运行模式和旧探针关闭；仅配置开关不代表已经验收或获得启用授权。Pi只从服务端只读文件加载桥接密钥及模型密钥，密钥不进入前端、模型上下文、镜像或响应日志。

新运行模式启用后，旧 `/assistant/probe` 和 `/assistant/setup/commands` 返回410，防止绕过计费。旧接口仅在 `APP_ENV=test`、`ASSISTANT_LEGACY_PROBES=true` 且运行模式关闭时用于第2/3项回归，不是可并存的试点入口。

在仓库根目录执行：

```bash
python3 scripts/test-assistant-isolation.py --chat-checks --report-dir /tmp/rp1-m4-checks
python3 scripts/test-assistant-isolation.py --setup-checks --report-dir /tmp/rp1-m3-regression
python3 scripts/test-assistant-isolation.py --report-dir /tmp/rp1-m2-regression
```

脚本构建锁定QA/Pi镜像，创建随机Compose项目、隔离网络、tmpfs PostgreSQL、合成账号/工位/归档及受控SSE模型。临时归档目录只挂载API和检查容器，Pi不挂载归档/数据库/设备/主机套接字，与PostgreSQL不共享网络。结束时清理隔离栈。前置条件为实际可用的Docker Compose及依赖/镜像仓库网络，不使用站点 `.env`。

在合成集通过后，可加 `--deepseek-key-file <已有服务端密钥文件>` 执行官方专项，仍只连接临时数据库和合成数据。真实模式选择官方专项而跳过合成故障夹具；本次真实专项已完成工位查询、明确建档、幂等重试和用量结算，不代表95%正确率或24小时观察。报告须使用新目录，不能覆盖上次证据。不得把密钥值写入命令、文档、报告或Git。

本次检查与版本证据见任务交付目录的源码清单、测试XML、`result.json` 和 `topology.json`。当前Pi镜像标签 `rp1-pi-bridge:0.4.0`，实际ID以对应检查记录为准。实施回归、真实模型、独立验收及24小时观察应分别保留证据，不能互相替代；当前状态请查任务交付报告。
