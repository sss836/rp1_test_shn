# 上位机第1版改造交接

本轮得到老板明确授权，连续推进已批准第1版的软件阶段。实际安装、软件发布服务启用和真实 PLC/CAN 操作仍需另行确认。必要开发自检不替代老板验收，不设置强制8小时运行门槛。

## 操作员会看到什么

- 登录测试平台后，后台检查兼容版本。检查失败只显示原因，不阻止登录或测试。
- 有可信新版本时显示当前版本、新版本及说明。执行员、管理员点击后才下载；其他已登录账号可查看提示。保留“稍后”和顶栏“检查更新”。
- 下载安装包使用独立软件通道，不走测试数据上传、原始 CSV 归档或审批接口。会话仅在内存中使用，不写入更新缓存。
- 正常结束与“软件失能”分别操作。正常收尾的阶段单独显示，保护操作仍可立即中断。
- 当前设备反馈缺少实际失能确认字段，因此安装准备检查会明确拒绝自动签发安全安装证明。已校验的包保留在本地；不能把下载完成写成已安装或已生效。

## 对接位置

| 文件 | 行为与连接 |
| --- | --- |
| `factory_hmi/desktop/app.py` | `_platform_login_ok` 触发检查，检查和下载进入现有后台任务；重复请求受 pending 限制；退出/更换账号使旧回调失效。显示独立收尾状态。 |
| `factory_hmi/desktop/quick_page.py` | 正常结束与软件失能分开；启动结果丢失走保护取消，不等待正常回位。 |
| `factory_hmi/client.py` | 图形端调用本地检查、下载及安装准备接口。 |
| `factory_hmi/gateway/software_updates.py` | 复用平台内存登录会话，先查询、验签，再下载到独立缓存。下载锁不占运动租约，也不占平台心跳锁。 |
| `factory_hmi/sync/reliability_platform.py` | 单独的软件目录和包下载请求；复制内存 cookie，拒绝重定向，短时版本查询不与包下载共用锁。测试档案提交规则不变。 |
| `factory_hmi/gateway/app.py` | 添加本地更新接口，正常停止调用 `finish`；保护取消调用独立 `abort`。 |
| `factory_hmi/version.py` | 网关创建时缓存实际加载代码的版本及进程标识，防止安装元数据变化被误报为旧进程已运行新代码。 |

## 尚需核对的启用条件

左右五自由度手臂的机械/线缆范围、映射和零偏、安全停放姿态、返回速度与加速度、到位误差和速度容差、稳定窗口与超时依据尚无已核实值。缺失参数时对应运动功能禁止启用。J5 命令范围不能替代机械允许范围；全零不能替代自然下垂姿态。

工厂系统和架构、依赖、平台访问及内网连通条件需核对后选择相应包。可信更新公钥、发布目录和发布版本需在单独授权部署时配置；本轮不启用真实发布服务、不发布生产版本。

## 运行与数据边界

补完当前周期属于实际测试运行；慢回、稳定和异常保持属于独立收尾。原始 CSV 不补写历史数据，回位证据不自动上传。`reliability_v1` 的用户核实、显式提交、归档校验及审批继续独立执行，未批准记录不进入正式统计。

## 后续协作约定

老板本轮直接要求：阶段验收后自动推进已批准范围内的下一阶段。本轮据此连续协调软件实施。安装、发布、真实设备操作以及未批准的新范围仍分别核对授权。本文件记录反馈，不直接改写办公室共享规则，也不表示其他项目已经得到实施授权。

实际产物、自检命令与结果、未完成事项由本轮交付记录列明，见 `outputs/animal-office/hmi-v1-implementation/`。
