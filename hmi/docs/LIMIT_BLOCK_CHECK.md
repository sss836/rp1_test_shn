# 工位限位块检查

当前交付在上位机左侧新增「限位块检查」，实现了可操作的模拟验收版。现场常规测试和本功能使用不同的执行入口。模拟结果不构成安装合格结论。

| 模块 | 检查范围 | 方向 |
| --- | --- | --- |
| 左／右单腿 | 5 或 6 自由度，按独立模块型号 | 各轴分别检查上限、下限 |
| 左／右单臂 | 5 或 7 自由度 | 各轴分别检查上限、下限 |
| 腰部 | 腰侧摆、腰旋转 | 两轴均检查机械限位块的两侧 |

腰部从标准腰髋配置提取两条总线上各一台 ID 1，排除两个髋俯仰 ID 2。踝俯仰与踝侧摆各自作为一个逻辑关节，分别检查时都绑定该侧两台闭链电机。参考角使用《RP1.3.4（量产版）URDF 关节限位及电机参数（20260916）》角度列。

### 操作

1. 选择模块、填写样机、勾选方向，应用方案。方案摘要包含样机、部位、每台电机的接口／ID／型号／方向、参考角、检查方向和本轮模拟参数。
2. 分别点击「连接」「使能」「复位」「开始搜索」。复位目标时程为 4 秒，也受位置过渡速度约束。回读达到起点容差后才允许另行开始搜索。页面显示当前最大起点角差。
3. 每项先接近参考角，在接近位置取力矩基线。低速试探时只推进一个逻辑轴。监控方向、角度停滞和力矩上升，命中候选条件就撤掉推进目标。
4. 反向沿刚才的实测姿态缓退，依据回读核对净退距离。点击「确认并继续」后先回到检查起点，再进入下一项。最后一次确认执行回起点与模拟失能。
5. 表格显示电机映射、参考角、候选角、偏差、净退距离与结果。结果区分参考范围内、提前阻挡、超出参考、未检出、中止及未覆盖。可全选、清除选择和逐项勾选。中止后保留已获得的证据。

### 信号与判据

`factory_hmi/core/limit_block_check.py` 的 `Coordinates` 校验具名关节顺序、CAN 接口和控制 ID，检查一组电机反馈均已更新、未过期且时间差受限。直接驱动轴按方向换算。踝部复用上位机闭链的角度正反解，根据当前位置求电机角对关节角的局部雅可比，使用 `τ_joint = Jᵀτ_motor` 换算关节力矩。两个电机缺一路、反馈数据重复或闭链映射丢失有效性都会中止。

`ContactWindow` 用连续 1 秒的新鲜数据核对三件事：角度跨度至多 0.2°，目标仍朝选定方向推进，全窗口力矩绝对值至少为 0.5 N·m 且比基线高 3 N·m。所示 1°/s 搜索速度、阈值、±3° 比对窗口、约 1° 缓退和演示中止门限只属于模拟设置。模拟器支持正常、提前阻挡、超出参考、未检出、反馈中断和超力矩。

`factory_hmi/desktop/limit_block_page.py` 负责动作按钮互锁与结果表。模拟使用 20 Hz 的虚拟反馈，界面以 8 倍速推进模拟时钟，保持反馈判定窗口。显式导出时，JSON 记录方案摘要、参考来源、原始模拟电机反馈、关节换算结果、候选依据及退路结果。所有报告标记 `source_kind=simulation` 和 `calibration_passed=null`。

### 真机接入条件

现场版需逐工位核定安全起点、允许的接近路径、探测行程、搜索 Kp/Kd 和各轴中止力矩。量产机械参考角可用于比较，不能单独确定这些控制参数。应在已经验证的网关工位租约与 CAN 独占内运行，用新鲜的驱动反馈在每次指令前核对状态，限制软件指令推进行程，允许现有急停抢占。增益从复位值平滑转入各轴搜索值。现行 108 使用驱动回读力矩，109 要确认实际 Kt 来源并记录估算性质。腰部实机接入应使用独立两轴映射，避免调用四轴腰髋使能。

真实搜索入口当前尚未接入，开发验证不发出 CAN、PLC 或电机命令。定稿前需分别实机确认正常止挡、提前阻挡、未检出、反馈中断和撤力后的机构安全；接触位置证据仍需结合安装复核。
