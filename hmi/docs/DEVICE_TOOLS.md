# 上位机设备测试

进入侧栏「IMU 初始化与检查」，填写实际接线的独立 CAN 接口，默认 can2。「初始化 IMU」和「检查回传」可以分别运行，均使用经典 CAN。

- 初始化先将主机设为 500 kbit/s，识别地址 8 的 HIPNUC 后写入配套初始化指令，再把主机切到 1 Mbit/s。初始化结果记录指令和接口状态。
- 检查可单独启动。在 1 Mbit/s 采集 5 秒，检查加速度、角速度、四元数的新鲜度与四元数模长，并显示各组实测帧率。已初始化的设备可以直接检查。
- 灵巧手使用同一窗口七自由度手臂配置的 CAN 和默认节点 1。读取状态会连接、让 SDK 配置反馈周期、读取一次六轴反馈并断开。显示位置、速度、电流、使能和故障码，无需给手指使能或回零。
- 手臂使能并静止保持、手指活动范围清空后，点击「开始运动」。按 GitHub Python wave_demo 的顺序连接、设置速度与电流限幅、使能、回零，按 50 Hz 发送位置指令。拇指两轴各往返 2 秒，其余四指波浪运动 6 秒，然后重复。反馈中每轴有去程和回程变化即满足运动条件。点击同一按钮「停止运动」后核对失能并断开，启动期间也可停止。故障、窗口心跳丢失或手臂失去静止保持会中断运动。共享 CAN 保持原有时序。
- 两项 IMU 操作和手部测试均使用内置协议。网关在状态目录 device-tools 中保存报告与样本。IMU 页面在完成后提供报告导出和回传频率摘要；灵巧手页面只保留两个操作按钮。
- 构建使用 Python 3.12 离线运行库。灵巧手扩展依据 Roboparty/roboparty_dexhand 的 3d2a5abb8f7299aea9ad7371ea94f37db87f79d6，由 tools/build_dexhand_sdk.py 构建。将产出的 wheel 安装到构建用 runtime 后，再运行 tools/build_local_deb.py。打包时校验扩展能加载并提供急停状态接口。
