# 上位机设备测试

进入侧栏「IMU 初始化与检查」，填写实际接线的独立 CAN 接口，默认 can2。两个页签可以分别运行，均使用经典 CAN。

- 初始化先将主机设为 500 kbit/s，识别地址 8 的 HIPNUC 后写入配套初始化指令，再把主机切到 1 Mbit/s。初始化结果记录指令和接口状态。
- 检查可单独启动。在 1 Mbit/s 采集 5 秒，检查加速度、角速度、四元数的新鲜度与四元数模长，并显示各组实测帧率。已初始化的设备可以直接检查。
- 灵巧手安装在七自由度手臂末端。在同一窗口配置对应手臂，确认其使能并静止保持后，从「灵巧手测试」连接。接口自动跟随手臂配置，保留共享 CAN FD 的 1 Mbit/s 仲裁和 5 Mbit/s 数据段配置。设置节点 ID，按页面操作使能、回零、检查、往返测试，可选择单轴或六轴依次测试。往返按是否观察到运动判定，故障和陈旧反馈会中止测试。
- 两项 IMU 操作和手部测试均使用内置协议。运行报告和样本保存在网关状态目录的 device-tools 下，页面可以导出。不需要为这些测试导入配置文件或 NPZ。
- 构建使用 Python 3.12 离线运行库。灵巧手扩展依据 Roboparty/roboparty_dexhand 的 3d2a5abb8f7299aea9ad7371ea94f37db87f79d6，由 tools/build_dexhand_sdk.py 构建。将产出的 wheel 安装到构建用 runtime 后，再运行 tools/build_local_deb.py。打包时校验扩展能加载并提供急停状态接口。
