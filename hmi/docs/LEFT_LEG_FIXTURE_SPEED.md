# RP1 PLC 上位机 3.0.37 legspeed1

**3.0.41 已暂停本文所述提速。** 工装专用 −20° 截止及轨迹继续生效。已核定方案使用 25 ms 最小命令间隔，转场最高 20°/s，远端搜索最高 10°/s，近限位最高 2°/s。下文保留 3.0.37 实验历史。详见 [3.0.41 限位验证与故障处置](LIMIT_CHECK_3_0_41.md)。


这是五轴左腿立柱工装的可选提速版本。上位机读取经工位核定的方案后，空行程转场目标最高为 60°/s，远端搜索最高为 40°/s。接近限位的最后 6° 最高为 2°/s，受限髋旋转区采用原低速。

内侧摆保持膝关节 −145°，在 −20° 截止并回退。该方向记录为“工装限行”，保留原机械下限参考 −42.73°。发生提前接触、力矩超限或反馈中断时，执行器按反馈处理。其余九个方向继续执行原检查。

## 工位使用

1. 按工位 Ubuntu 版本选用 22.04 或 24.04 的 amd64 安装包，核对 SHA256。核实停测、电机失能、PLC 总停止反馈后，按现有升级流程更新并核对新进程版本。
2. 五轴左腿配置示例在本发布附件和源码的 `hmi/config/examples/left_short_leg.sequence.draft.json`。工位负责人须核对实际工装、关节映射与运动间隙，填写核定人。已核定的方案由工位管理员配置为 `/etc/rp1-factory-hmi/limit-probe.d/left_short_leg.sequence.json`，沿用现有管理员属主与权限要求。安装软件后，提速须通过此工位方案启用。
3. 隔离环境中，完整控制线程连接模拟电机，从开始运动到请求失能用时 116.3 秒，含报告落盘约 117.0 秒。固定有效反馈间隔为 10 ms 时用时 118.47 秒，20 ms 时为 141.92 秒。真实工位的有效反馈周期、负载、受阻和缓退情况决定实际节拍。第 6 项近柱最小间隙约 3.6 mm 是模型估算值，现场尚需实测。

Ubuntu 22.04 和 24.04 安装包均通过断网容器安装、mock 健康检查及左腿全程预检。限位检查回归 169 项通过，补充反馈越界用例后，4 项工装专项全部通过。本发布沿用 v3.0.36 发布附件中的重建资源包，两版的应用资源摘要一致。
