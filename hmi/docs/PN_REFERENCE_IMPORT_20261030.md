# Pn参考资料接入：RoboPartyDiver 0.6.0

本次接入用户提供的 `RoboPartyDiver_0.6.0_Pn协议与参数说明_20261030.zip` 中九个Pn的静态参数定义，供维护人员查看和报告追溯。资料描述USB/串口Membus，尚未证明适用于LRO CAN读写。

## 已提供的能力

参数维护窗口新增“查看Pn参考资料（适用性待核实）”。该只读窗口展示九项参数的名称、16位无符号定义、原始范围/默认值、倍率、单位原文、生效标记及来源哈希；无需调用网络、CAN、PLC或参数写入。

含Pn的维护报告增加独立 `reference` 字段，保留资料来源、参数集编号和原始文件行号。该字段不进入管理员模板、不改变模板哈希和新值、不替换实际读回，也不参与比较通过或写入授权。归属未知的回包显示为“未核验响应原始值”。

0401的倍率0.01与单位原文0.01ms、0F09/0F0A的倍率0.1与单位原文0.1A分别保存；不对CAN未核验回复做物理量换算，不因单位文字再次缩放。0E05按十六进制展示范围和默认值；没有添加资料未提供的掩码逐位解释。

## 仍保留的限制

资料没有确认LRO型号/硬件与完整固件适用关系、CAN上的Pn响应关联、设备最大回复时间及掉电保存保证。Membus中的16位参数字段、CRC及写回显不能直接替换现有CAN中的 `C0 10/C0 11` 和 `FF FE 11` 处理。

生产Pn读取继续保留原始响应并标 `association_unknown`，不计通过；含未知Pn的整批写入预览被拒绝。常规KT、编码范围、CAN超时的已确认模板读写流程保留，人工重新上下电声明与独立回读仍分开，不新增保存命令或供电控制。
