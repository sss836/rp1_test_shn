# 本地执行记录、SN 筛选与执行台账

老化测试页的本地执行记录区新增日期、SN 查询、分页、目录快捷入口和台账 CSV 导出。无需登录平台即可查询本机已完成记录；本机网关原有操作令牌检查仍保留。

## 使用

- 日期按执行开始时间和本机时区计算。今日包含今天全天；一周以内为今天及前六天；一月以内从一个月前的同一日期到今天；自选时间段包含结束日全天。全部日期包含未提供原始时间的历史补录，其余范围不猜测这些记录的日期。
- SN / 模块编号支持完整或部分匹配，不区分大小写。输入停顿或回车后筛选，可与日期组合。标识保留字符串、前导零、大小写及长编号，不转换为数字。
- 每页 100 条。导出记录 CSV 导出当前日期与 SN 条件的全部结果，不受显示页、最近 100 条或 1000 条限制。它是执行清单，不拼接或修改原始采集 CSV。
- 选中记录后，“打开记录目录”打开该测试编号的文件夹；未选中时打开统一执行记录目录。网关在另一台电脑上时，只有当前电脑能够访问该路径才可打开，失败会显示真实路径。
- CSV 使用带 BOM 的 UTF-8。CSV 本身没有列类型，Excel 导入时将模块编号 / SN 列设为文本，防止 Excel 自行丢弃前导零或长编号精度。可能被解释为公式的文本单元格加单引号保护，原始记录不变。

## 本地文件组织

实际路径由当前网关的状态目录决定，不写死桌面或源码目录。多个窗口共用 report_root 的执行记录与台账：

```text
DATA/executions/
  执行台账.csv
  <本地测试编号>/
    manifest.json
    telemetry/raw.csv
    analysis/summary.json
    analysis/report.md
    config/...
```

目录以不可变的本地测试编号命名。平台后续确认的正式单号列在台账中，不据此重命名封存证据。台账同时列出本地测试编号、模块编号 / SN、起止时间、判定、最近同步和审批状态、记录目录及原始 CSV 路径；路径可以直接追溯到具体执行。

台账是可重新生成的本地索引，启动恢复、新记录完成封存、历史补录和列表刷新时更新，始终覆盖全部记录，不受当前筛选限制。写入使用共享证据锁、临时文件、fsync 和原子替换，避免窗口并发互相覆盖或半份 CSV。台账写入失败时仍显示已有记录，并在界面说明失败；原始证据保持不变。同步 / 审批状态反映最近一次刷新，不替代平台审批事实。

## 文件与接口

- `desktop/app.py`：筛选控件、后台查询与过期回复防护、分页、文件管理器和导出入口。
- `client.py`：携带相同日期 / SN 条件调用列表和导出；目录由网关返回。
- `gateway/app.py`：`GET /api/v1/executions`、`GET /api/v1/executions/export.csv`、`GET /api/v1/records/location`。起始时间含边界，结束时间不含边界；非时区时间和倒序区间拒绝。
- `core/service.py`、`core/report.py`：完整记录读取、同步状态批量关联、台账原子更新，以及按本地测试编号解析目录。
- `execution_history.py`：日期 / SN 选择、稳定时间排序、CSV 视图；`sync/outbox.py` 批量读取指定记录的状态，避免只关联最近 1000 条。

查询、台账和导出不会触发上传、提交或审批。原始测量事实、执行包及 `reliability_v1` 核实、归档和统计边界保持原有规则。软件自检使用临时数据和 mock 设备；是否安装、生效或现场通过须分别报告。
