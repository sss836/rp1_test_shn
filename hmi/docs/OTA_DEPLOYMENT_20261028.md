## 404 的原因和修复

之前上位机已装入新版，但平台 API 仍是 2026-10-23 的旧镜像。实际 OpenAPI 不含更新路由，容器内也没有 OTA 模块，因此版本查询返回 404。

此次基于旧 API/Web 的实际镜像制作局部覆盖镜像，未把工作区其他未交付的业务改动一并部署。新增软件分发通道沿用真实平台会话与角色；原始测试数据的归档、核实和审批路径未改动。

上线联调还发现固定使用 `Path(__file__).parents[3]` 在容器 `/app/app/services` 布局中得到 `/`，导致任何发布目录都被判为与项目重叠。`backend/app/services/hmi_updates.py` 已改为根据应用根目录确定边界，保留源码仓库与容器应用目录的禁止重叠检查。新增容器布局回归测试，31 项隔离测试通过；实际容器中的存储初始化也已通过。
