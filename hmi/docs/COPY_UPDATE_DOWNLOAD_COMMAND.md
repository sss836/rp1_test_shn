# 更新下载与复制安装命令

2026-10-29 按老板要求调整：点击“下载更新”就通过当前已登录的网关下载并校验，将完整安装包保存到缓存。下载前只提供“下载更新”和“稍后”；收到 `status=staged` 及有效 DEB 绝对路径后，完成窗口提供“复制安装命令”和“打开下载目录”。不再让用户复制下载脚本重复下载。

复制内容为 `sudo apt install <下载回执中的实际安装包绝对路径>`。使用 shell 参数引用，包含中文、空格、引号及 shell 特殊字符的路径仍是同一个字面参数，不会执行路径中的命令替换。相对路径、非 DEB 路径和控制字符被拒绝。复制不会执行命令、再次下载、退出实例或安装；窗口保持打开，仍可查看实际路径或打开目录。

下载链路：界面“下载更新” → 当前上位机网关 → 已登录平台专用软件通道 → 原有验签、SHA256、DEB 信息校验及缓存 → 返回实际路径 → 显示复制安装命令入口。权限、发布版本变更、下载互斥和失败恢复沿用既有网关。没有新增匿名包地址、测试附件或数据归档通道。下载失败或缺少完成回执时不显示可安装成功提示，也不更改剪贴板。

保存位置来自网关实际回执，不猜测为桌面或“下载”目录。默认缓存仍为 `STATE/data/software-updates/releases/<release_id>/`。若桌面连接远程网关，路径属于网关电脑，安装命令须在该电脑执行；当前电脑无法访问目录时打开目录按钮如实提示。复制命令不包含平台密码、会话 Cookie 或网关令牌。

## 安装与运行边界

新增按钮在安装并运行含本次改动的新版本后出现，既有已发布的 2.0.19 包没有这次 UI 修改，不能同版本覆盖发布。复制安装命令不等于自动安装或安全停机证明。执行 apt 前仍须按仓库约定确认测试停止、电机失能及设备安全状态，正常关闭旧实例，用同一状态目录的 `rp1-test-hmi status` 确认 `running=false`；安装后核对实际版本、进程身份与健康状态。不强杀控制实例、不删除锁、配置或记录，不自动使能或启动测试。
