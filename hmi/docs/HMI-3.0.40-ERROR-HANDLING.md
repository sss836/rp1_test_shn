# 上位机 3.0.40 报警与状态读取修复

本地源码以 `v3.0.39`（`2e48abc`）为基线。安装包构建和更新发布已按要求暂缓。

## 姿态验证的读取时机

原生驱动在一次读取期间观察到收帧计数变化，会返回空批次，避免把不同时间的数据拼成一个姿态。原来的预检和启动直接把第一次空读作为操作失败。现在整模块预检、启动和单方向复位共用 `FactoryService._read_probe_entry`，在原有 150 毫秒预算内以最多 8 毫秒的等待间隔重取空批次。超出预算仍会拒绝启动。非空批次继续走原有的数据校验，驱动异常直接向上传递。运行中的运动循环沿用原有的时限和处理规则。[工位服务](../factory_hmi/core/service.py)

`Coordinates.decode` 指出 CAN 口、电机 ID、关节和该轴具体失败的校验，包括时间戳、反馈时延、驱动报警、使能位、位置和力矩。读数过期时给出时延与阈值。同一轴上同时出现多个异常时会列出各项。真机采样阶段的协议、力矩来源、温度和速度错误也标明对应轴。[姿态解码](../factory_hmi/core/limit_block_check.py) · [原生后端](../factory_hmi/core/backend.py)

## 多轴报警与失能反馈

`FactoryMainWindow._rest_failed` 逐项显示同一条记录里的 ID 和故障码。给定 `id=7:error_id=2, id=3:error_id=7`，窗口分别显示 ID 7 报 2、ID 3 报 7。含 `can1#3` 或驱动协议名等其他格式的原始详情也会保留。[桌面端](../factory_hmi/desktop/app.py)

控制器将本次故障保护结果附在本次异常上，网关直接调用和独立工位进程均传递该结果。界面分开显示失能请求和反馈确认。请求发出后没有新反馈、发送失败、读取确认结果失败有不同表现。操作没有返回失能结果时，界面提示核对逐轴反馈。[控制器](../factory_hmi/core/controller.py) · [故障保护](../factory_hmi/core/fault_response.py) · [工位进程](../factory_hmi/gateway/station_process.py)

## 关闭失败后的快照

开始收尾后如果设备释放失败，服务保留首次失败原因，继续拒绝新运动。显示采集器可以取得专用于关闭过程的快照，包含关闭状态和原因，期间无需访问驱动。当关闭失败后重新启动显示采集时，HTTP 和 WebSocket 可继续读取这一状态。关窗重试仍须收到工位释放回执。其他场景中缺少新鲜快照时，后台状态轮询退避两秒，在连接标识上显示等待状态。操作错误仍留在原提示位置。[工位服务](../factory_hmi/core/service.py) · [桌面状态与关窗逻辑](../factory_hmi/desktop/app.py)

## 灵巧手共线读取

手臂运行、暂停、正在停止或保护状态下，页面读取网关已有状态。若有同一窗口、配置版本、CAN 接口和节点的历史报告，标出报告时间，否则提示暂无匹配反馈。网关也独立核对实际手臂状态，在构造灵巧手 SDK 前拒绝冲突的请求。手指正在本窗口往复时仍可刷新已有反馈和停止。正常空闲或已确认全部失能的工位可直接读取灵巧手。通过 SDK 新建连接的路径依然只使用手臂实际绑定的 CAN 接口。[页面](../factory_hmi/desktop/device_tools_page.py) · [共线准入](../factory_hmi/gateway/device_tools.py) · [设备报告](../factory_hmi/core/device_tools.py)

## 验证

使用临时工位目录、模拟驱动、离屏 Qt 和本地测试 HTTP 客户端。姿态测试使用 3.0.39 已随包分发的回放资源。覆盖单次空读后恢复、持续空读超时、逐轴反馈错误、发送失败与回读未确认、多轴弹窗、关闭失败后持续返回 HTTP 200 且携带首因、关闭重试、灵巧手运行中冲突和带时间的缓存。此轮未连接现场 PLC 或 CAN，未做长期稳定性或实机安装验收。

针对上述修复的 195 项测试全部通过。扩展回归有 103 项通过、6 项失败，另有 17 个子测试通过。以下六项失败均已在原版 3.0.39 上复现。

| 测试位置 | 断言所见 |
| --- | --- |
| `test_factory_default_return.py` | 模拟反馈过期时，回默认位已被拒绝，测试随后检查电机立即失能的断言失败。 |
| `test_service_lifecycle.py` | 四个断言分别涉及空工位创建证据锁、一个工位关闭失败后平台关闭调用次数、关闭后 SQLite 文件句柄、孤立采集文件恢复后归档副本的换行字节。 |
| `test_wp1_desktop.py` | 快速验证结束按钮的提示文案与旧断言不一致。 |
