# 工厂质量摘要与参考判据

工厂模式下，七种内置快速验证项目都使用 `factory-quality-v2` 自动筛查。普通轨迹测试使用同一部位、同一个内置文件、同一电机映射、1 倍速和 20 Hz 记录时，也可使用相同判据。更换轨迹文件、倍率、采样频率、电机 ID 或型号时保留数据并说明不匹配的原因，不套用旧数值。

原参考测试由现场确认按界面 1 倍速运行。右腿旧记录的实际指令周期约 18.73 秒、轨迹文件周期 14.98 秒；旧短臂分别约 21.07 秒和 12.64 秒。差异不代表操作员选择了其他倍率。当前内置短臂也与旧短臂文件版本不同。新判据明确标为试行，旧记录仍保留原判定。

七轴腕部补查了本机 7 条正常完成、无电机故障的七轴左臂历史记录。逐记录从原始 CSV 重算后，腕偏航的最大 RMS / 绝对误差 P99 / 绝对力矩 P99.9 分别为 0.0989 rad / 0.1759 rad / 4.387 N·m；腕俯仰为 0.0681 rad / 0.1220 rad / 5.659 N·m。误差保留 50% 裕量，力矩保留 40% 裕量，分别向上取整到 0.01 rad、0.05 rad、1 N·m。历史记录未保存当前轨迹哈希和倍率，不能视为当前 1 倍工况已验证。

逐电机最高温度上限 **60 °C**，峰值温升上限 **20 °C**。P99、P99.9 都用线性插值分位数。峰值温升是最高温度减去开测前段窗口的温度中位数，窗口取前 60 秒与有效时长 10% 中较短者。速度不作为工厂质量指标。这些数值不参与运行保护，也不作为正式放行、可靠性或 MTBF 统计依据。实际装夹、负载和散热不同需重新验证。

运行须达到本次时长或圈数目标，至少完成一圈、无故障、采样完整率 ≥95%、最大相邻间隔 ≤0.20 秒、时间严格递增且必要电机字段齐全。符合这些前提后，全部指标均小于或等于上限才通过；超限记录具体电机、实测、上限、单位和超出量；未达到前提时显示「未判定」及原因，保留实测数据。例如模拟记录中，七轴腕偏航 ID 6 的绝对力矩 P99.9 实测 8.25 N·m，上限 7 N·m，超出 1.25 N·m，结果为「试行不通过」。

上位机启动记录时在 `config/execution.json` 冻结本次判据、工况和电机映射。原始 CSV 封存后，报告进程写入 `analysis/summary.json` 和 `analysis/report.md`。在「本地执行记录 → 查看摘要」可以同时查看筛查结论、判据来源、执行目标与实测时长、圈数、采样证据及逐电机实测。六个试行部位明确标为「试行通过 / 试行不通过」。旧冻结的 v1 判据仍可重算，重算追加分析版本；不改写原始数据、历史原结论或审批状态。

实现位置：`core/factory_quality.py` 固化并评估判据，`core/service.py` 冻结本次策略，`core/streaming_metrics.py` 使用磁盘暂存计算逐轴指标，`core/report.py` 封存结果，`desktop/app.py` 显示本地摘要。

隔离验证覆盖七个内置项目的报告封存与 JSON 校验、超限数值、未判定原因、桌面摘要和旧 v1 重算；另用模拟电机跑完腰胯、左七轴臂和左短腿的内置快速验证，核对自动筛查结果。未操作真实 CAN 或 PLC。扩大回归中的旧执行台账测试在改动前的 `34b9f6a` 上同样失败。
