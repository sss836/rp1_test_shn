# 工厂质量摘要与参考判据

普通轨迹和快速验证在明确选择工厂模式后，冻结本次部位、轨迹 SHA256、倍率、记录频率、电机通道和试行阈值。原始 CSV 封存后，报告进程从采样数据计算逐电机指标，并把工厂质量状态、实测值和阈值写入 `analysis/summary.json` 与 `analysis/report.md`。可从“本地执行记录 → 查看摘要”查看，原始 CSV、已有记录判定、核实和审批独立保留。修改判据后只对新执行生效，重算历史会追加分析版本。

工厂质量的三类指标为电机位置误差、温度和力矩反馈。P99 为绝对位置误差的 99% 分位，P99.9 为绝对力矩反馈的 99.9% 分位，均以线性插值分位数计算；最高温度和峰值温升逐电机比较，温升基准为开测前段窗口（取前 60 秒与有效时长 10% 中较短者）的温度中位数。速度字段不进入质量指标。

只有执行正常到达本次设定时长或圈数、至少完成一圈、无故障且记录可用时才判定质量。采样完整率至少 95%，最大相邻间隔不超过 0.20 秒，时间严格递增，必需的电机测量列完整。执行中断或工况不匹配时，摘要显示“未判定”与原因；任一电机的质量指标超过阈值时显示“不通过”与对应指标。

试行阈值取正常约四小时参考执行的逐通道最大值，对跟踪指标保留约 50% 裕量，对力矩 P99.9 保留约 40% 裕量，并按显示精度向上取整与保留小量程下限。所有匹配工况逐电机的试行温度上限为 **60 °C**，峰值温升上限为 **20 °C**。这些是工厂筛查值，装夹、负载、控制参数和散热需现场保持可比。

用户已确认这些参考测试均按界面 1 倍设定。历史执行未保存 run_request.speed，不能由时长、圈数或指令周期反推操作者选择了其他倍率。右腿记录的实际指令周期约 18.73 秒、原文件周期 14.98 秒；旧短臂约 21.07 秒、原文件周期 12.64 秒。这是记录中的节拍差异，原因仍待核对实际运行代码、播放与记录时间口径。不能把等效的0.8或0.6时间缩放当作已保存的设定倍率。右腿和旧短臂保留阈值建议，但在节拍差异查明前不自动套用质量通过；腰胯现有1倍参考继续适用。旧短臂文件与当前内置文件还存在哈希和方向差异。其他部位仍保存实测摘要，等补齐对应工况的基线再启用自动判定。现有参考记录数量不足以推断批量公差或放行能力，温度与力矩也不作为设备运行限值。

实现位置：`core/factory_quality.py` 固化试行规程，`core/service.py` 冻结本次策略，`core/streaming_metrics.py` 在现有磁盘暂存上计算分位数，`core/report.py` 封存结果，`desktop/app.py` 显示本地摘要。
