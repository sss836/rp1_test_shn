# 工厂页布局更新（2026-11-04）

按用户认可的效果图实现并部署，前端修订为 `factory-layout-20261104`。

## 页面变化

- `frontend/src/components/FactoryMonitor.tsx`、`factoryMonitor.css`：四格本页概况；台架按卡片展示，默认桌面三列，窄屏二列/一列。每台只显示一项主要上报，完整会话与编号放在原生可展开详情。离线内容明确为历史快照，空会话不堆叠零时长。故障优先，台架编号按自然顺序显示。
- 待办以SN、台架、真实状态和“查看记录”为主，超过5条可展开；离线提醒合并显示。没有目标值时不绘制虚构进度。后台仅标记上传未完成时，显示“上传未完成”，不暗示文件正在传输。
- `frontend/src/pages/FactoryPage.tsx`：沿用原导航，保留上传入口，取消重复的记录标题。
- `frontend/src/pages/ArchivesPage.tsx`、`factoryLedger.css`：仅嵌入式工厂台账使用新分支。筛选保持一行，统计压缩为五格条，表格以SN/测试、台架、时间、归档和审批状态展示，完整标识折叠保留。非嵌入页面沿用原渲染。
- `frontend/src/factoryApi.ts`：归档状态和记录链接共用大小写无关的精确执行UUID匹配，不按SN合并复测。

## 保留的行为

原有15秒页面陈旧、20秒采样陈旧、45秒离线判断，以及分区冲突隔离、角色权限、分页、CSV导出与真实审批语义保留。暂停自动刷新或请求失效后，不继续显示绿色实时运行。SN大小写及前导零不被规范化。

没有修改API、数据库结构、归档数据、账号权限、原大屏或上位机软件。本次无需重新安装上位机。
