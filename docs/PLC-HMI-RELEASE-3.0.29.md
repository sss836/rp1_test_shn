# RP1 PLC 上位机 v3.0.29

提供 Ubuntu 22.04 和 24.04 的 amd64 DEB。默认平台地址为 `https://10.43.17.214:8443`。原位升级继续使用工位已有的地址、证书和本地记录。

- 同一 CAN 上可为 108 和 109 电机分别启用经核实的协议。109 的 Iq 单独显示和记录。缺少力矩实测的记录不会通过依赖力矩的工厂筛查。
- 在「电机版本 / 固件下载」中，可对整模块或指定 108 电机发起升级。默认匹配 2026 年 10 月 28 日 15:37 的 109 固件哈希。上位机记录刷写文件和回读版本，逐台核验后继续。
- 参数窗口可对勾选的电机运行只读检查。108 显示普通参数实测值，109 增加 Pn 实测值和脚本参考差异。

109 现场控制需要经核实的工位配置，刷写需要对应硬件的签名固件与转换策略。配置、使用步骤和固件基准见[电机维护说明](../hmi/docs/PLC_HMI_LRO_108_109.md)。

升级前确认测试停止、电机失能及 PLC 实际反馈已停止。正常退出旧上位机，用原状态目录运行 `rp1-test-hmi status`，确认 `running=false` 后安装对应系统的 DEB。安装后正常启动，核对包版本及新实例的进程启动时间和网关健康状态。
