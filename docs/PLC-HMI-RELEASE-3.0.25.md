# RP1 PLC 上位机 3.0.25

本版提供 Ubuntu 22.04 和 Ubuntu 24.04 的 amd64 安装包。默认平台地址为 `https://10.43.17.214:8443`，保留工位显式配置的地址和证书。登录与本机回环曲线预览分别使用平台和本地网关。

- 隐藏 PLC 页面使用状态摘要，保留故障、连接状态和命令回执。打开页面时仍读取趋势和操作日志。
- 区分 WebSocket 链路状态和电机反馈新鲜度，关闭窗口不再重连或渲染迟到回执。
- 预览检查入口及资源，缺失时给出明确提示。平台登录分别显示连接、证书、超时和账号错误。控制与采样周期及现场保护阈值保持原样。

## 从源码构建

切换到 `v3.0.25`。Ubuntu 24.04 amd64 可按 [HMI 源码构建说明](../hmi/README.md) 执行。需要 Node.js 22 和 npm；构建脚本从锁文件安装前端依赖并生成本机预览，预览产物不提交 Git。Ubuntu 22.04 包使用对应平台构建的 SDK、打包用 Python 3.12 及标准库，见 [Ubuntu 22.04 部署说明](../hmi/docs/UBUNTU22_DEPLOYMENT.md)。

## 下载和校验

从 [v3.0.25 Release](https://github.com/sss836/rp1_test_shn/releases/tag/v3.0.25) 下载与工位系统对应的 DEB 和 `SHA256SUMS`，执行 `sha256sum --ignore-missing -c SHA256SUMS`。源码标签中的 HMI 实现与安装包源码逐项比对，本机预览重新构建后与两包内的 54 个资源逐项一致。对应系统的隔离验证覆盖了 mock 启停、预览、缺资源恢复与平台默认配置，未操作现场 PLC/CAN。
