## 已安装电脑更新

1. 确认当前测试停止、电机已失能且 PLC 已总停止，正常退出上位机。使用同一用户及状态目录的 `rp1-test-hmi status` 确认 `running=false`。
2. 下载完整 DEB，运行 `sha256sum rp1-test-hmi_3.0.18+ubuntu24.04.platformupdate1_amd64.deb`，与本文摘要核对。
3. 在该目录执行：

```bash
sudo apt-get -o Dpkg::Options::="--force-confold" --reinstall install "$(pwd)/rp1-test-hmi_3.0.18+ubuntu24.04.platformupdate1_amd64.deb"
dpkg-query -W -f='${Version}\n' rp1-test-hmi
```

4. 从桌面正常打开，核对新实例显示的版本。保留原状态目录、配置与测试记录。新电脑首次安装同样使用此完整包，按现场实际地址设置 HTTPS 平台及 CA；不要复制其他工位的安装身份。

上传或安装完成不代表旧进程已替换，也不代表真实机械臂验证通过。本次发布未执行设备动作，未完成七天长测或带载验证。
