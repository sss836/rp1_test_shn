# RP1 PLC 上位机 v3.0.30

Ubuntu 22.04 和 24.04 amd64 安装包的默认平台地址为 `https://10.43.17.214:8443`。

本版新增 `rp1-test-hmi stop --site-isolated`。操作员在现场确认共用柜、受影响工位及外部电源均已隔离，且测试已停、电机已失能、机构已支撑后，可用此命令正常退出。退出时先收尾工位、记录和 CAN，再停止 PLC 轮询并关闭软件连接。隔离确认写入 `data/plc/shutdown.jsonl`，PLC 电气反馈记录为未核验。

普通 `stop` 继续核对实机停机反馈。隔离退出的回执不作为自动更新所需的正常总停证明。启动器和网关都必须已加载本版功能，旧进程需要先按现场维护流程正常退出。[使用说明](../hmi/docs/LOCAL_CONTROL_BUILD.md)
