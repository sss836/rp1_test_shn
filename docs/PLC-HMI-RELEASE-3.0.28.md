# RP1 PLC 上位机 v3.0.28

本版提供 Ubuntu 22.04 和 24.04 的 amd64 安装包。默认平台地址为 `https://10.43.17.214:8443`。升级时，工位已有的平台地址、证书和本地记录继续使用。

- 连接 CAN 后可以按请求编号查询回执。重复查询复用本次结果，慢状态刷新不阻塞回执确认。界面只接受对应工位和当前配置的连接结果。
- 工厂模式封存记录后，按内置轨迹、1 倍速、20 Hz 和电机映射匹配判据，报告显示逐轴实测值、上限和超出量。左右五轴和七轴臂采用 v3 试行值，历史记录可用冻结判据复算。参见[逐轴判据与来源](../hmi/docs/FACTORY_QUALITY_TRIAL.md)。
- 工厂快速验证和普通轨迹测试的循环阶段继续采集实际速度。单独超出工位速度阈值不再触发停测。位置、驱动故障、反馈有效性等检查及首帧接近、暂停保持和收尾的限速仍生效。参见[快速验证与保护边界](../hmi/docs/QUICK_VERIFICATION.md)。

安装包、源码及 SHA256 校验见 [GitHub Release](https://github.com/sss836/rp1_test_shn/releases/tag/v3.0.28)。Ubuntu 22.04 包内置便携 Python 3.12，Ubuntu 24.04 包使用系统 Python 3.12。系统更新入口提供签名的相应 Ubuntu 包。

升级前确认测试已结束、电机已失能和 PLC 实际反馈停止。正常关闭旧上位机，并在原状态目录用 `rp1-test-hmi status` 确认 `running=false`。安装后核对包版本和新实例的启动时间及网关状态。工位姿态、撤力和 PLC/CAN 仍需现场验证。
